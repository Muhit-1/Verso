What this mockup decides: (1) taskbar options live under Settings > Desktop, not as a desk widget; (2) six controls only — auto-hide, alignment, size, and the three buttons — everything else stays in Windows' own page, one click away; (3) a small preview shows what each choice does; (4) every change applies immediately and shows a toast with Undo, the same pattern as the launcher; (5) “Reset to Windows defaults” puts all six back (Left is NOT default on Windows 11 — default = centred, medium, all three buttons on, auto-hide off).
Real build, not shown here: values are written to HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced (TaskbarAl, ShowTaskViewButton, TaskbarDa, TaskbarSi), …\Search\SearchboxTaskbarMode, and auto-hide through the taskbar's own StuckRects3 setting; Explorer is told to refresh (no restart); on a read error a control shows as unavailable instead of guessing. Changes made in Windows' own settings page show up here when the tab is opened.
