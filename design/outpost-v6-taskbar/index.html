Use a compact dock instead of the taskbar
Windows' full-width bar is hidden. A small floating dock shows only the apps that are open right now — as wide as those icons, nothing more — and appears when you open an app and disappears when the last one closes.

Show minimised apps

The dock sits where the taskbar position below says (bottom, top, left or right) and follows alignment and size. Things only the real taskbar has — badges, flashing, jump lists, pinned-but-closed apps — are not in the dock; turn it off to get them back.

Position and size of the taskbar are newer Windows settings; Verso reads and writes the same values Windows does, and “Reset to Windows defaults” always puts them back.
What changed after your screenshot: (1) the group now mirrors Windows' own “Taskbar behaviors” page — same names, same order, same position thumbnails (Bottom / Top / Left / Right), alignment, size (Small / Default / Large), auto-hide (only enabled at the bottom, with the same note), badges, flashing, all displays (greyed out with one monitor), share window, far corner, combine buttons — plus Search / Task view / Widgets. (2) New Compact dock: Windows' bar is hidden and Verso shows a small floating pill with only the open apps, which appears with the first open app and disappears after the last one closes. Use the preview's “+ Open app / − Close app” to see it. When the dock is on, the Windows options below it are greyed out (they would have no visible effect) but keep their values.
How the dock would be built (so you can judge it): it must be a real always-on-top window, not part of the wallpaper layer, created without taking focus; it lists top-level windows the way Alt-Tab does (visible, not tool windows, not cloaked), shows each app's real icon, click = bring forward / minimise, middle-click or the usual shortcuts unchanged; the real taskbar is hidden with the same method as today's “Hide taskbar”, and the screen edge peek slides it back for a moment. Honest limits: no badges, no flashing, no jump lists, no pinned-but-closed apps (you asked for open apps only), the system tray and clock are only reachable through the peek, full-screen apps hide the dock like they hide the taskbar, and every Windows update could change how Explorer treats a hidden taskbar — so it needs a spike (S0) before the real build, like the desktop-icon drag had.
Before building each Windows option: Verso will first confirm, on this PC, which registry value Windows changes when that option is toggled (position and size are new on this Windows build, so I will not guess the keys). Any option I cannot make reliable stays out and the “Open Windows taskbar settings” button covers it.
