# Video wallpapers

Drop `.mp4` or `.webm` files here — wherever you found them — purely
for your own organization. There is nothing to install: open the tray's
**Set background…** and pick the file directly; Verso plays it full-bleed,
looped, muted, via a plain HTML5 `<video>` element in the existing
WebView2 layer. See [docs/plan.md](../../docs/plan.md), Phase 3, for why
that's a `<video>` tag and not a native video-player dependency.

Nothing scans this folder automatically — it's a shelf, not a catalog.
